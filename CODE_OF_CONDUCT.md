# Code de Conduite — ECU Master Lab

## Notre Engagement

Nous nous engageons a rendre notre communaute plus accessible, respectueuse et inclusive. Chaque participant a le droit d'etre traite avec dignite et respect.

## Nos Standarts

Comportements acceptables :
- Utiliser un langage respectueux et inclusif
- Respecter les points de vue et experiences differents
- Accepter la critique constructive
- Se concentrer sur ce qui est le meilleur pour la communaute
- Montrer empathie envers les autres membres

Comportements inacceptables :
- Harcelement sous toutes ses formes
- Langage sexiste, raciste, ou discriminatoire
- Menaces ou attaques personnelles
- Publication d'informations privees sans consentement
- Spam, publicite non sollicite

## Domaine d'Application

Ce code de conduite s'applique dans tous les espaces du projet, y compris :
- Les issues et pull requests sur GitHub
- Les discussions sur les canaux de communication
- Les interactions en personne lors d'evenements lies au projet

## Enforcement

En cas de violation, nous pouvons prendre des mesures allant d'un avertissement a une exclusion permanente du projet.

## Signalement

Tout incident peut etre signale en ouvrant une issue privee ou en contactant les maintainers directement.
